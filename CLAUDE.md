# j-maths — working notes

Interactive maths simulations for A-level Maths / Further Maths (OCR MEI). Static site, no build step, served from the root of `main` on GitHub Pages at `https://jacobgoodchild.github.io/j-maths/`.

## Status
Built (all eight from the brief), each with tabs:
1. **Unit circle** — circle and graphs · sine and cosine together · identities · phase shift
2. **Maclaurin series** — Maclaurin · about a point (Taylor) · convergence
3. **Riemann sums** — sums · convergence (log n) · area function (FTC)
4. **Distributions** — binomial · Galton board · normal · sample means (CLT)
5. **Derivative tracer** — gradient function · first principles
6. **Matrices as transformations** — transformation · combining · 3D (unit cube, 3×3 matrix editor, eigenvectors)
7. **Newton–Raphson** — Newton–Raphson · basins · fixed point (cobweb) · bisection
8. **Volumes of revolution** (three.js) — solid · between two curves (washers)

Next: polish. See "Polish list" at the bottom.

## Layout
- `index.html` home grid, driven by `assets/js/registry.js` (add new sims there). Previews are `assets/previews/<id>-{light,dark}.png`, regenerated by `tools/previews-all.sh`.
- `sims/<id>/index.html` + `main.js` per sim. All paths are relative so it works in the `/j-maths/` subfolder.
- `assets/css/kit.css` — all styling (theme tokens at the top). `assets/js/kit/*` — the shared kit:
  - `shell.js` page, tabs (`#tab-id` in the URL), settings cog · `ui.js` slider / toggle / segmented / dropdown (KaTeX in options) / readouts / transport
  - `plot.js` canvas graph helper: dpr-crisp, axes/ticks (auto, π, degrees, log, integer), pan + zoom + reset-view, draggable handles (keyboard: arrows move, Enter switches handle), curve() that breaks at asymptotes, fillBetween, arrows, `inset`/`pin` for axes at the edge
  - `theme.js` light/dark + `colors()` for canvas · `tex.js` KaTeX · `anim.js` loops · `funcs.js` shared function library (f, f′, f″, F) with Gauss–Legendre quadrature · `rng.js` sfc32 + Box–Muller + exact binomial pmf
- `assets/vendor/` local KaTeX, three.js (+ OrbitControls). Fonts in `assets/fonts/` (Instrument Sans, Newsreader).
- Pure maths lives in separate modules so it can be tested in node: `sims/*/series.js`, `riemann.js`, `mat.js`, `nr.js`, `assets/js/kit/{funcs,rng}.js`. `assets/js/kit/scene3d.js` is the shared three.js wrapper (volumes + matrices 3D); pages that use it need the importmap.
- `tools/`: `shot.mjs` (screenshots a sim in light + dark, prints console errors: `node tools/shot.mjs sims/unit-circle tab1,tab2`; images go to /tmp/claude-0/shots/), `previews*.mjs`, and `test-*.mjs` (run them all with `for f in tools/test-*.mjs; do node $f; done`).

## Decisions (and changes from the brief)
- No build step. ES modules; KaTeX via its `.mjs`; three.js via an import map in the volumes page only.
- Colour roles (CSS variables, readable in both themes): function = blue, approximation/thing being built = orange, error = pink-red, tangent/derivative = green, area/angle/sample = violet, construction = teal, warning = amber. sin/cos/tan have their own vars (blue/orange/green).
- UI accent is plain ink (black/off-white), so the maths colours carry the meaning. Switches are coloured to match the thing they show.
- Unit circle: circle and graph share one vertical scale so the dashed link line is continuous across two canvases; the band is vertically centred so no dead space.
- Unit circle "unwrap" tab was replaced by "Sine and cosine" (cosine drawn sideways under the circle so it lines up with the horizontal projection).
- Maclaurin: the slider counts non-zero *terms* (as the brief says), so sin/cos/arctan don't have dead steps; the formula shows the actual degree P_n(x). (1+x)^n uses exact fractions (BigInt) for coefficients; for a non-negative integer n the slider stops once the polynomial is exact. Validity band marks open/closed end-points.
- Riemann: the strip count slider steps through a fixed list (1…1000) so keyboard steps are uniform. Upper/lower sums use dense sampling for sup/inf (exact for monotone functions).
- Distributions: sample (empirical) = violet, theory = orange throughout. Histograms rescale smoothly. Galton board animates up to ~70 balls at once; above that the rest are counted instantly so it stays smooth at 10k/s.
- Derivative tracer: the derivative trace only draws over the x-range the point has visited. The "interesting" functions are |x|, ∛x, tan and x²sin(1/x).
- Matrices: determinant colour flips to pink and the orientation arc reverses when det < 0. Animation uses the preset parameter (rotation turns, not shrinks).
- Newton–Raphson: failure cases are examples in the dropdown (flung away, cycle, diverges, unexpected root, repeated root). Extra tabs: basins, cobweb, bisection.
- Volumes: the surface geometry is refilled (not rebuilt) when only the sweep angle changes. Rotating about the y-axis uses π∫x² dy and only works for monotone curves with a ≥ 0 (the button disables otherwise).
- Phones are not handled yet (brief says a later session does that). Pointer events are used so touch mostly works.
