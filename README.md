# j-maths

Interactive maths simulations for A-level Maths and Further Maths (OCR MEI) and beyond. Each sim takes one idea and lets you see it.

Live site: https://jacobgoodchild.github.io/j-maths/

It is a static site (plain HTML, CSS and ES modules, no build step). To run it locally, serve the folder with any static server, e.g. `npx serve .`, and open the home page.

Developer notes, decisions and open questions are in [CLAUDE.md](CLAUDE.md).
